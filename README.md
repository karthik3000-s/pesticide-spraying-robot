# Remote-Controlled Pesticide Spraying Robot

A Wi-Fi controlled robot for spraying, driven from the Blynk IoT app.

## Features

- Remote driving of the robot
- Spray on/off control
- LED control
- Temperature and humidity monitoring

## Hardware

Arduino UNO, ESP8266, L298N motor driver, DC motors

## Software

Arduino IDE, Blynk IoT app
